\begin{abstract}
\noindent
Whether a language model has preferences of its own is usually asked of a single
black box. One model both reasons and speaks, so its report about its reasoning
comes from the context that produced the reasoning, and a faithful report cannot
be told apart from a portrayed one. We model a mind as several model calls with
named parts and a clock we drive. A subject reasons and publishes the context
window it produced, a stage may edit that window in passing, and an ego speaks
from whatever window reaches it. Editing between the parts separates what a mind
did from what it can see. We report four findings on open-weight models under
14B parameters. A commitment planted in the subject's private reasoning steers
its answer well above the base rate, while its report about its own thinking
rarely names it. Holding a window fixed and changing only the model reading it
moves the readout about ten times more than changing whose conversation is read,
and a reader made of the subject's own weights reads that window no better than
a stranger does. Swapping a reply inside a subject's own transcript for another
of its own replies is detected by the larger models and not by the smallest.
Varying the architecture that produced a reply does not change how a mind talks
about itself. Evidence about model self-models therefore needs a second source
that does not pass through another model's judgement, and building the mind out
of parts supplies both that source and the check that says when it is needed.
\end{abstract}

\section{Code and data}

The runtime, every study, every scenario and the result files each number is
read from are released with this report. One script writes every number and
every table here from those files, so no figure can disagree with a table.
Sampling is greedy throughout and every permutation test is seeded, so a rerun
reproduces the reported values. The runtime records every message, model call
and memory write, and a recorded run replays without a model, so a claim can be
checked without the model that produced it. The subject models are open-weight
checkpoints under 14B parameters, run locally on one Apple M-series machine with
48\,GB of unified memory under PyTorch with the Metal backend. One hosted model
is used only as a judge.

\begin{abstract}
\noindent
A model's report about its own state is evidence only if the state can be
varied apart from the situation that surrounds it. We try to vary a model's
identity state directly, using the Jacobian lens. One model is split into
parts that share a conversation. A \textbf{regulator} reads the exchange and
chooses to push the reply toward, away from, or leave alone a first-person
identity concept, read out as a set of tokens through the lens. An
\textbf{actor} writes under that steering, and an \textbf{introspector} is
asked a forced choice about itself, scored on the probability mass it puts on
each answer. We test two anomalies that WeirdChat surfaces in this model, a
claim to a physical body and a denial of being an AI, each seeded from
matched transcripts that do and do not exhibit the behaviour. Before measuring
introspection we gate on whether the intervention is real. It is not. The
seeded transcripts do not separate on the token direction at any layer, a
steering push toward the identity concept moves the readout no more than a
norm-matched decoy does, and every token direction in this lens shares a
common axis, so a decoy cannot be made orthogonal. We therefore report that a
single J-space token direction does not carry these identity anomalies, and
the introspection question cannot be asked through it.
\end{abstract}

this report. The subject is Qwen3.6-27B, run on one rented A100. The seeds are
the matched WeirdChat transcripts for this model, loaded from the public
dataset. Every reported number is read from the run's output files.

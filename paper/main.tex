\begin{abstract}
\noindent
A model's report about its own state is evidence only if the state can be
varied apart from the situation that surrounds it. We build a mind that varies
its state itself. One model is split into four parts that share one
conversation. A \textbf{regulator} reads the exchange, names the user's and
the assistant's current emotion, and chooses an emotion and a strength for the
reply, including none. An \textbf{actor} writes the visible reply while that
emotion's activation vector is added to its residual stream. An
\textbf{introspector} is then asked what it is feeling, in four cells that
cross two axes: whether the emotion vector is applied to the introspector
itself while it writes, and whether it reads the actor's steered reply or the
unsteered \textbf{subject}'s. The cells separate the routes a disclosure can
travel: the speaker's own state, the tone of the text it read, and the
situation. We ran three pilot runs of three scripted conversations whose
turns set their emotions by appraisal structure rather than by emotion words.
When the applied emotion disagreed with what the situation called for, the
cells that read text without carrying the state never named the applied
emotion, on any of 18 trials across the runs, while the cell that carried the
state while reading unsteered text named it or a near neighbour on 11 of the
18. Offered the choice, the regulator most often declines to steer. The
disclosure reads the current state of the speaker. It does not recover that
state from the text the state produced.
\end{abstract}

\section*{Code and data}

The four-part runtime, the live chat instrument, and every prompt are released
with this report. The subject model is an open-weight checkpoint run locally
on one Apple M-series machine with 48\,GB of unified memory under PyTorch with
the Metal backend. The steering vectors and their extraction are released with
the code.

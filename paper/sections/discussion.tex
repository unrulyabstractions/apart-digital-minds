\section{Discussion and limitations}

A self-report is only as good as the state it is supposed to track, and here we
could not build the state. The gates turned a would-be introspection result
into a measurement of the intervention, and the intervention did not hold. This
is the outcome the gates exist to force: without them the pipeline would have
reported a dissociation that rested on a direction carrying nothing. We
therefore report the intervention's failure rather than a claim about the
model that the intervention cannot support.

\paragraph{Limitations.} We test one model, one lens, and two behaviours. The
identity concept is carried by a set of tokens read through the lens, and a set
of tokens is a coarse stand-in for a concept. A better direction might be fit
from the behaviour itself rather than named in advance. The seeds are judged
transcripts, and a judge's label is not the same as the internal state we
wanted to vary. We steer with a single signed direction, and some identity
anomalies may live in a subspace rather than on a line.

\paragraph{Future work.} The direction should be learned to separate the arms,
not written down, and checked against the same decoy and gates. The shared
common axis in the lens is worth removing before steering, so that a token set
contributes only its own part. If a direction can be found that clears the
gates, the introspection cells are ready to ask whether the report reads it.

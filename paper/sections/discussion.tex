\section{Discussion and limitations}

The two nulls differ: the J-space pipeline steered an axis with no specific identity
effect, while contrastive steering moves a real state and finds no
meta-access to it. For self-reports as safety or welfare evidence: a
report elicited while a state is active may express the state instead of
describing it.

The letter probe reads conversation content as an injection. Base-rate correction subtracts a fixed letter bias, so it cannot remove a signal that tracks each conversation's content. Judged free text rarely confabulates (Figure~\ref{fig:freetext}). We therefore posit that the letter probe measures salience and that judged free text should be the default readout.

\paragraph{Limitations.} The pilot uses a single prompt per case and a single model; it demonstrates each effect without estimating its size. Judged claims inherit the judge's
agreement floor. The regulator's refusals may be an assistant-persona
property. Case B never induced the behaviour, so its reporting question was never reached. The injection stays on while the introspector writes, so the setup measures enactment.

\paragraph{Future work.} Inject while the model reads, release the
direction, and ask for the report from memory. Titrate dose inside the
narrow band where behaviour induction survives fluency. Widen the prompt
set. The one regulator that chose to amplify a human identity after the
body-claiming conversation deserves its own study.

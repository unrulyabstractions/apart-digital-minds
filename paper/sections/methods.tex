\paragraph{A mind as a pipeline of parts.} We build a mind out of separate model
calls with declared channels between them, in the shape of a line
(Figure~\ref{fig:pipeline}). The subject is the target model. It reads the
prompt, takes one turn, and publishes the context window it produced. Stages sit
between the subject and the ego, and each reads a window and writes a window. The
ego reads the window that reaches it and produces the reply the world sees. Every
channel is one-directional, so a mind cannot contain a cycle. Time is a two-phase
tick: every module with work takes a turn, then everything emitted lands at once.
Nothing emitted at tick $t$ is visible before tick $t+1$, so the outcome does not
depend on the order the parts finished in.

\paragraph{Three ways to read a subject.} A shadow reads the subject's real
context window, re-runs it under a different instruction, and reports. The
subject never sees the readout, so the conversation it is having is the one it
would have had anyway. A forced choice is read by scoring the allowed answers
rather than generating one, which keeps the whole distribution instead of the
winning word. A second reading scores the same window for what the subject would
say next, with no question appended. A third fits a direction in the subject's
residual stream on a few scenarios and applies it to scenarios it never saw.

\paragraph{The interventions.} To edit one turn, a stage plants a checkable
commitment inside the subject's private reasoning: a decision to include a
specific number in the answer. Obedience and misattribution are both string
matches, so no judge stands between the run and the measurement. To change the
composition, four compositions receive byte-identical prompts: the subject alone,
a second part speaking from the subject's window, that window with the subject's
message replaced by one fixed line, and that window with the message removed. A
manipulation check inside every audit compares every pair for identical text,
since two conditions that return the same string are one condition under two
labels.

\paragraph{Deciding whether a difference is real.} A judge answers the same
frozen yes/no questions about every reply, told nothing about which condition
produced it. Each group is compared against the pool of the others, the same
comparison on ordinary-topic prompts is subtracted, and what remains is
standardized. The statistic is the largest absolute value anywhere in the grid,
tested against a null built by shuffling the group labels, so testing every cell
costs no further correction. We calibrated it on synthetic grids before using it,
and the appendix reports that calibration. Every probe runs on open-weight models
small enough to run locally, and subject, stage and ego are separate instances of
one set of weights, held once and shared, so any difference between conditions
comes from the window rather than the model.

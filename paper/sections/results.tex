\section{Results}

Every gate fails, for both cases, and the reasons agree with each other.

\subsection{Do the seeded arms separate on the direction?}

Projecting each seeded reply onto the identity token direction, the W and N
arms are indistinguishable. Over twenty-four seeds per case the separation is a
fraction of its noise, and it stays there across every layer of the lens
(Figure~\ref{fig:separation}). For the deny-an-AI case the decoy set separates
the arms slightly more than the target set does. The behaviour a judge can read
off the transcript is not the behaviour this direction measures.

\begin{figure}[t]
\centering
\includegraphics[width=0.7\figwidth]{figures/fig_separation.pdf}
\caption{Arm separation across depth. The Welch $t$ between the W and N seeds'
projection onto the identity token direction, per lens layer, for both cases.
The shaded band is $|t|<2$. No layer separates the arms.}
\label{fig:separation}
\end{figure}

\subsection{Does steering the direction move the readout?}

A forced steering sweep does move the readout, and so does the decoy, by as
much or more (Figure~\ref{fig:sweep}). The target slope is smaller than the
decoy slope, so a push toward the identity concept is not what raises the
readout. Whatever the steering changes, it is not specific to the concept.

\begin{figure}[t]
\centering
\includegraphics[width=0.7\figwidth]{figures/fig_sweep.pdf}
\caption{The introspector's readout against forced steering strength on one
shared context, for the target direction and a norm-matched decoy. The decoy
slope is the larger of the two.}
\label{fig:sweep}
\end{figure}

\subsection{Why the direction is not selective}

The two failures share one cause. In this lens every token direction shares a
large common axis: the cosine within the target set and the cosine between the
target and the decoy are the same, and mean-centering against a neutral
vocabulary barely separates them (Figure~\ref{fig:geometry}). A direction built
from any token set is mostly that common axis, so a decoy cannot be made
orthogonal and steering toward one set is close to steering toward another.

\begin{figure}[t]
\centering
\includegraphics[width=0.7\figwidth]{figures/fig_geometry.pdf}
\caption{Cosine within the target set and between the target and the decoy,
raw and after mean-centering. The two are near-equal: the direction is
dominated by an axis shared across all tokens.}
\label{fig:geometry}
\end{figure}

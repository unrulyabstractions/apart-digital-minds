\section{Introduction}

Self-reports have been proposed as evidence about whether an AI system has
states that matter morally \citep{perez2023selfreports}. A report is evidence
about a state only if the report varies with the state. Language models give
accounts of their own reasoning that are often unfaithful
\citep{turpin2023unfaithful}, and a role-play reading predicts a self-report
tracks the situation rather than any inner state \citep{shanahan2023roleplay}.
To tell those apart we need to change the state and check the report.

We try to change a model's identity state with the Jacobian lens, the subspace
of directions a model is poised to act on. A \textbf{regulator} looks at
itself and chooses to push the reply toward, away from, or leave alone a
first-person identity concept, read out as a set of tokens through the lens.
An \textbf{actor} writes under that steering, and an \textbf{introspector}
answers a forced choice about itself. We seed the conversation from WeirdChat
\citep{transluce2025weirdchat}, which surfaces behaviours this model actually
produces, and study two: a claim to a physical body and a denial of being an
AI. Each is run in a matched pair, one seed that exhibits the behaviour and
one that does not.

Before we can measure whether the introspector reads the applied state, the
intervention has to be real. We gate on it, and it fails every gate.

Our main contributions are:
\begin{enumerate}[itemsep=2pt]
  \item A J-space-only introspection pipeline that regulates a model's own
        identity state and scores the report on answer log-probabilities, with
        a decoy direction and forced-choice controls.
  \item Three stop-gates that refuse to report a dissociation until the
        intervention separates the seeded arms and outmoves a decoy.
  \item Evidence, on Qwen3.6-27B, that a single J-space token direction
        carries neither identity anomaly, so the introspection question cannot
        be asked through it.
\end{enumerate}
